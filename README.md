# petal — revision prototype

Open `index.html` in a browser to try the prototype.

Current prototype:
- Elegant responsive dashboard
- Subject progress cards
- Automatic-looking revision priorities
- Mistake tracker modal
- Local browser interaction for adding mistakes
- Mobile-friendly layout

Next build steps:
1. Add persistent storage (e.g. Supabase/Firebase).
2. Add authentication.
3. Add an AI endpoint to classify mistakes.
4. Build the revision algorithm.
5. Add original practice-question generation.
6. Test with 5–10 students before adding payments.
